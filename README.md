# Torega TCG

Site oficial da equipe Torega TCG.

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar build de produção

```bash
npm run build
```

## Publicar na Vercel

Suba este projeto para um repositório GitHub e importe o repositório na Vercel. O projeto usa Vite e não precisa de configuração especial de build.

## Imagens

Coloque o logo em `public/toregafoto.jpg`.

As fotos dos jogadores podem ser colocadas em `public/players/` quando forem adicionadas ao código.
